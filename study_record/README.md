# Study Record

```text
study_record/
├── learning-roadmap.md
├── completed/
├── env/
├── datatype/
├── architecture/
├── memory/
├── persistence/
├── replication-ha/
├── cluster/
├── observability/
├── security/
├── engineering/
└── opensource/
```

- `learning-roadmap.md`：全年任务全集；
- `completed/YYYY-MM.md`：按月完成账本；
- `专题/*.idx.md`：专题状态、文章关系和修订历史；
- `专题/*.md`：最终文章；
- `专题/evidence/`：实验与源码取证证据。

结构仿照 PostgreSQL 学习仓库（/data/myfuture/dba_one_year/study_record），
任务基线为 Redis 8.6.2。
